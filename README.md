## 绕不开的短板：无快照备份，以及一次机房火灾

这是搜稳定性信息时最该看清楚的部分，也是大多数测评文章一笔带过的。

RackNerd 的 KVM VPS 不提供快照（snapshot）备份。2024 年 12 月 V2EX 上一位的帖子把这件事说得很直白：楼主把海外公司项目放在 RackNerd 一台约 $40/年、2 核 4 GB 的机器上，运行一年多业务稳定，但没有快照可做兜底——而此前 RackNerd 某机房发生火灾，部分用户数据丢失，楼主自述“逃过一劫”，最终决定迁去 AWS。

这条信息是论坛用户转述，官方没有详细的事故说明可查，火灾的具体机房、时间和影响范围都无从核实。但它指向的风险是实的：**单实例 + 无快照，意味着数据安全完全取决于你自己的备份习惯**。ssh 上去之后第一件事就该配 cron 定时备份，把数据推到机器之外的地方。同帖有回复者说得也有道理：火灾属于低概率事件，怕出问题可以买两台不同机房的机器做冗余，年付十几美元的机器，两台也就一顿饭钱。

顺带一提，RackNerd 的共享主机产品线倒是带 JetBackup 免费每日异地备份——但它家主打的是 KVM VPS，买 VPS 就是拿 root 自己管。

还有两个使用层面的限制值得知道：

1. **换 IP 的成本**：购买后 72 小时内可在控制面板免费自助换一次 IP，之后每次 $3。如果分到的 IP 对你的场景不好用（比如被某平台标记），这个费用要算进去。
2. **IP 质量有波动**：有少数用户报告过特定 IP 存在丢包或不稳定，换到的 IP 也未必更好；有中国移动用户遇到过 IP 被封的情况，官方的建议是使用美西（加州）机房改善中国方向的连接。
